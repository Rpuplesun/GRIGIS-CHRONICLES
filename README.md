# 그리기스 연대기 (GRIGIS CHRONICLES)

악마 침공 방어전. 브라우저에서 바로 플레이: https://rpuplesun.github.io/GRIGIS-CHRONICLES/

이 저장소는 플레이용 빌드만 담고 있습니다.

## 조작

- 유닛: 클릭·드래그로 선택 → 바닥 클릭으로 배치 (Q W R 소환, T 영웅)
- 건물: A S D F G → 칸 클릭 (건물은 바닥, 방벽·충격 함정은 길 위) · U 강화 (Lv.2 타워는 U → 1/2 특화)
- 길 편집: E — 길과 벽을 칠해 악마가 걷는 길을 바꾼다 (입구와 심장은 이어져 있어야 한다)
- Z 심장 공명 · Shift+2~5 멀티 원군 지원 · 1 2 3 속도 · Space 일시정지 · Tab 지도(멀티) · Esc 취소
